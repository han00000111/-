# 交付验收清单

## 基础命令

- [ ] Node.js 版本为 22.x。
- [ ] 执行 `npm install` 成功。
- [ ] 执行 `npm run lint`，无 error；现有 warning 单独记录。

## 启动验证

- [ ] 执行 `npm run dev`，访问 `http://127.0.0.1:5173/`。
- [ ] 页面首次加载无白屏，浏览器控制台无阻断性异常。
- [ ] 导航切换正常，刷新后仍可进入应用。

## 构建验证

- [ ] 执行 `npm run build:prod`，生成 `dist/index.html`、`dist/404.html` 和 `dist/assets/`。
- [ ] 执行 `npm run build:demo`，生成 `dist-demo/index.html` 和 `dist-demo/404.html`。
- [ ] 执行 `npm run preview:prod`，production 产物可访问。
- [ ] 执行 `npm run preview:demo`，demo 产物可访问。
- [ ] demo 的 `index.html` 无外部 JS/CSS 资源依赖，可离线打开。

## 页面验证

### 总览页

- [ ] KPI、设备健康、当前任务、待关注事项和近期日志正常展示。
- [ ] 页面跳转入口可进入对应业务页。

### 设备总览

- [ ] 设备列表、筛选、搜索、详情和状态展示正常。
- [ ] 刷新状态、连接检查在当前权限下反馈正常。
- [ ] 导出内容与当前筛选结果一致。

### 任务管理

- [ ] 队列、详情、记录和人工接管相关页签可切换。
- [ ] 搜索、筛选、排序和导出结果一致。
- [ ] 暂停、恢复、取消、重试和下发按钮按权限与状态正确启用或禁用。

### 机器人监控

- [ ] 地图、机器人位置、底盘状态和运行日志正常展示。
- [ ] 手动摇杆覆盖层可操作，安全条件不满足时给出明确提示。
- [ ] 模拟指令可形成日志和回执闭环。

### 地图编辑

- [ ] 地图切换、点位、路线、区域和障碍物正常展示。
- [ ] 编辑、保存、删除等 mock 操作反馈正常。
- [ ] 自动建图状态与日志区域正常展示。

### 视觉识别

- [ ] 相机、模型、任务和识别结果正常展示。
- [ ] 结果复核、转人工和任务重试反馈正常。
- [ ] 图片标注区域无明显错位。

### 报警互锁

- [ ] 报警列表、详情、互锁矩阵和处理记录正常展示。
- [ ] 确认、恢复、忽略操作按权限和确认规则执行。
- [ ] 报警跳转目标正确。

### 日志审计

- [ ] 运行日志、操作审计和相关分类可切换。
- [ ] 搜索、筛选和导出结果一致。
- [ ] 日志详情字段完整，无明显乱码。

## 分辨率验证

- [ ] `1366×768` 下导航、主内容、弹窗和关键操作按钮无不可用遮挡。
- [ ] `1024×768` 下页面可滚动访问全部关键内容，无横向布局截断导致的不可操作项。

## 模式验证

### demo 模式

- [ ] `.env.demo` 使用 `VITE_RUNTIME_SOURCE=mock`、`VITE_ENABLE_MOCK_RUNTIME=true`。
- [ ] 页面动态数据按间隔变化，且不发起真实 API/WS 请求。
- [ ] `dist-demo/index.html` 可离线打开。

### production 模式

- [ ] `.env.production` 使用 `VITE_RUNTIME_SOURCE=static`、`VITE_ENABLE_MOCK_RUNTIME=false`。
- [ ] 页面数据保持静态，不启动 mock 定时器。
- [ ] 当前 `VITE_USE_MOCK_SERVICE=true` 的交付限制已向部署方说明。

### WS 失败降级

- [ ] 使用测试环境设置 `VITE_RUNTIME_SOURCE=ws`、`VITE_ENABLE_WS_RUNTIME=true` 和不可用 WS 地址。
- [ ] 页面保留静态初始数据，不白屏、不无限重连。
- [ ] 实时连接状态最终显示异常或关闭，其他导航与查询功能仍可使用。

## 验收结论

- [ ] 所有阻断问题已关闭。
- [ ] 未关闭问题均已记录到 `docs/known-issues.md`，并确认交付影响。
